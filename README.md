The funniest one-line cat joke I could write (104 characters, one line):

> My cat knocked my glass off the table while holding eye contact — she wanted me to know it was personal.

Every cat owner knows the glass-knocking. The turn is that the cat does it on purpose, holding eye contact — not clumsy, but personal. No tired puns, no explanation after the punchline.

## Run it

```sh
python3 main.py
```

It prints the line and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), the file the make.fun program/v1 harness grades.
